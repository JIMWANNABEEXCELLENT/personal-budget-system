# 生活費與消費監控看板 (Personal Budget & Expense Tracking System)

結合工業工程（IE）「視覺化管理」與「防呆機制（Poka-Yoke）」概念的個人雲端記帳系統。透過 Google Apps Script 串接 Google 試算表與自製 RWD 網頁介面，將日常記帳流程極簡化，解決傳統記帳軟體步驟繁瑣、難以持續的痛點。

## 核心功能與系統亮點

* **視覺化安燈監控看板（Andon Board）：** 網頁頂部即時顯示本月剩餘生活費與日均可用額度。進度條與看板背景會依據預算消耗比例自動變色（50% 以下為安全綠、達到 50% 轉為警戒黃、超過 80% 轉為危險紅），在超支前提供直覺的視覺預警[cite: 5]。
* **高頻消費一鍵記帳與防呆設計：** 將日常高頻開銷（如早餐、飲品）設計為獨立快捷按鈕，點擊後自動寫入雲端並暫時鎖定按鈕狀態，防止連點造成重複入帳；同時支援自訂快捷項目與「一鍵撤銷」功能[cite: 5]。
* **QR Code 快捷識別卡產生器：** 針對固定消費品項，可一鍵生成專屬掃碼通行卡與快速記帳網址，搭配手機捷徑或掃碼即可直接觸發後端入帳，省去手動輸入時間[cite: 7]。
* **衝動消費即時預警：** 區分「必要」與「想要」兩大消費類別，當系統記錄到非必要開銷時，自動透過後端觸發郵件通知，在消費當下建立心理摩擦力以控制預算。

## 系統架構與使用技術

* **前端介面（`index.html`）：** HTML5 / CSS3 / JavaScript，採行動裝置優先的響應式設計（RWD），支援單手快速操作與動態 DOM 樣式切換。
* **後端邏輯（`Code.gs`）：** Google Apps Script (GAS)，負責處理前後端非同步資料傳輸（`google.script.run`）、預算比例運算、URL 參數解析與自動寄信邏輯[cite: 6]。
* **雲端資料庫：** Google Sheets，零伺服器建置成本，自動留存完整消費明細與動態更新統計報表。
